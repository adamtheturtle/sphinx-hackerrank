# 2026.11.01.4 (2026-11-01)

## Changes

- Declare each Interviewer Guideline part explicitly with `guideline-part` and its own groups and selections.
  Parts render in declaration order.
  Repeat layout declarations where parts share groups, and require content through each part's selections.

  This replaces the RST `:parts:` and `:required-for:` options.
  Python layouts now contain `GuidelinePart` objects in `GuidelineLayout.parts`, replacing shared groups, `part_headings`, and `GroupRequirement`.
  Missing or ambiguous parts and empty required selections still fail the build.
  ([#23](https://github.com/adamtheturtle/sphinx-hackerrank/issues/23))
