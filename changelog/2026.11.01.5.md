# 2026.11.01.5 (2026-11-01)

## Changes

- Use explicit RST recipes as the single Interviewer Guideline authoring workflow.
  Remove the Python layout configuration, `:layout:` option, and manual `interviewer-guideline-section` directive.
  Keep body selections, alternative headings, shared sections, and site-wide configuration for varied guide structures.

  Recipe selections accept exact heading paths and standard RST section labels as well as literal headings.
  Literal headings take precedence, including names containing `/`.
  Exclude separately selected descendants by source identity so repeated names and slash punctuation cannot redirect exclusions.

  Remove the former manual workflow's parsed-guide cache and duplicate post-render admonition pass.
  Filter selected source sections and included introductory RST directly during composition.
  Each mapped language is parsed once per composition, with native include and incremental-build dependency tracking retained.
  Update validation to exercise the public RST workflow against native rendering.
