# 2026.10.31 (2026-10-31)

## Changes

- Remove the built-in guide vocabulary and layout policy.
  Callers now provide `hackerrank_guideline_layout` using `GuidelineLayout` and `SectionGroup` to choose the marker, headings, grouping, retained headings, closing sections, and introductory RST.
  Derived views require this explicit configuration.
  Existing section-selection directives remain available.
