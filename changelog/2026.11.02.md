# 2026.11.02 (2026-11-02)

## Changes

- Narrow the package to portable HTML export.
  Remove the composition directives, layout model, and `compose_guide` API.
  Author disclosures with `sphinx-toolbox.collapse` and excerpts with `sphinx-section-include`; consumers own content filtering, heading presentation, and validation.
- Remove automatic loading and runtime dependencies on Jinja, section inclusion, and collapse extensions.
  Install and enable authoring extensions explicitly.
- Embed the code-copy script only in standalone exports.
  Ordinary Sphinx pages can use `sphinx-copybutton` without duplicate buttons.
  Preserve standalone copying, keyboard operation, fallback behavior, and script-free rendering checks.
- Update the sample and installed-wheel checks to use ordinary RST, retain admonitions, and declare the sample's authoring dependencies separately.

- Embed local images and image links as data URLs so diagrams remain available when fragments are moved or uploaded.
  Preserve external image URLs without fetching them, and reject missing or unsupported local image assets.
