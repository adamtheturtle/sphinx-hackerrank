# 2026.11.01.2 (2026-11-01)

## Changes

- List exact part headings under `:parts:` and `:required-for:`, one per line.
  Every listed heading must exist, so these lists need no minimum counts.
  Punctuation is literal, and missing or duplicate names fail the build.
  Pattern-based recipes must migrate their selectors to `:part-pattern:` and `:required-for-pattern:`.
  Python layouts can use `part_headings` while retaining the existing `part_pattern` API.
